# Part 100 kickoff — part 99 shipped both launcher fixes; v1.0.1 is next in line

Part 99 (2026-09-06) executed `docs/localization-and-bootskip-plan.md` end to
end — subtitle-language selection and the skip-intro-logos toggle, the two fixes
the operator queued ahead of v1.0.1. Both are in-tree, gated, defaults chosen

because none of this touched the renderer.

## §0 What part 99 established (the short form)

* **Subtitle language** (e1da647, 42d558d): six banks ship (en ja fr es it ko);
  the ID→bank mapping was measured, not derived (one `CZ_FILE_TRACE` boot per
  `CZ_LANGUAGE=N`; 3=de and 8=zh fall back to en and are not offered). One
  `CzLanguage()` helper answers both HLE sites so they cannot disagree; the
  launcher's SUBTITLES row persists the Xbox ID; there is deliberately no
  in-game row (the title reads the value ONCE at boot — A1). The id-4049
  LS→MASH rewrite now lands in all six banks (fr ships `LS` without the
  trailing space; the gate accepts both), generator v3→v4 across the part.
* **The boot-logo skip** (42f99bc): the plan's mechanism was WRONG and the
  correction is recorded in place (plan §5 + `runtime/cpu/boot_skip.cpp`'s
  header). The logos are not top-level states — BCGIntro is never requested;
  the chain is Startup → LegalScreen (7 ms) → Loading → FrontEnd
  (`CZ_STATE_TRACE=1`, new instrument), and the visible sequence is
  **fecmn.big's `intro.txt`**, an event-chained cFEAnim timeline (~18 s). All
  three state-substitution spellings were built, run, and REFUTED (one
  null-deref, two hangs — each state's enter kicks work the next state waits
  on); the title's own `skip_startup` tunable does nothing visible. What
  shipped is a **data patch**: `assets/game_bootskip/fecmn.big` (intro.txt
  keyframe times renumbered per-anim 1,2,3… — every event still fires, each
  logo a one-tick flash), generated by BOTH overlay generators
  (byte-identical, first build) and served as its own VFS layer only while
  `skip_intro_logos` is on. The black legal card is load-driven and untouched.
* **Gates run**: three-layer C++/Python identity (bootskip + patched + kbm all
  `diff -r` clean); A5 kernel diff unchanged in both toggle states
  (permutations only); skip ON reaches deepest file #85 with zero faults; skip
  OFF never consults the layer. The state table is at **0x82A5912C** — the
  plan's 0x82A6912C was a typo that zeroed every `--find-uses`.
